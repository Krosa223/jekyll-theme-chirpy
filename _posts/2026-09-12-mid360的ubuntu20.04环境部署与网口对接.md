## 参考教程

本文针对 CSDN 教程：

https://blog.csdn.net/m0_55117804/article/details/142644882

进行技术审查。

该教程整体流程方向正确，包括：

-   安装 Livox-SDK2
-   编译 livox_ros_driver2
-   配置 MID360_config.json
-   启动 ROS 节点

但是部分步骤默认了作者自己的实验环境，缺少关键前置条件说明，在不同电脑、不同网络环境下容易失败。

------------------------------------------------------------------------

# 一、最大的问题：把"作者环境"当成"通用规则"

很多 Livox MID360 教程存在同样问题：

作者环境：

    电脑：
    192.168.1.50

    雷达：
    192.168.1.xxx

然后教程直接告诉读者：

修改：

    MID360_config.json

即可。

实际情况：

MID360 的 IP 是雷达自身参数，不是 ROS 配置文件决定的。

必须区分：

## 电脑 IP

例如：

    192.168.1.5

作用：

接收雷达数据。

------------------------------------------------------------------------

## 雷达 IP

例如：

初始：

    192.168.2.192

修改后：

    192.168.1.10

作用：

雷达网络地址。

------------------------------------------------------------------------

## ROS 配置 IP

例如：

``` json
host_net_info:
{
"cmd_data_ip":"192.168.1.5"
}

lidar_configs:
{
"ip":"192.168.1.10"
}
```

只是告诉驱动：

"电脑在哪里" "雷达在哪里"

不会改变硬件 IP。

------------------------------------------------------------------------

# 二、教程中最容易误导的地方

## 1. 关于雷达 IP 的说明不严谨

部分教程写：

    雷达IP最后两位来自SN码

这种说法容易误导。

实际：

MID360 默认 IP 与 SN 末尾数字没有直接数学关系。

例如：

SN:

    47MDM6B0020392

不能推出：

    192.168.1.92

或者：

    192.168.1.192

本次问题：

雷达真实 IP：

    192.168.2.192

不是因为序列号。

------------------------------------------------------------------------

# 三、3.5 配置文件步骤的问题

教程通常要求修改：

``` json
"host_net_info"
```

和：

``` json
"lidar_configs"
```

但是缺少：

## 第一步：确认雷达真实 IP

应该先执行：

    livox_lidar_info_get

或者：

    tcpdump -i 网卡

确认：

    雷达当前IP

否则直接填写：

    192.168.1.xxx

属于猜测。

------------------------------------------------------------------------

## 第二步：确认电脑有线网卡 IP

使用：

    ip addr

确认：

例如：

    enp88s0

    192.168.1.5

不要使用：

    wlo1 无线IP

------------------------------------------------------------------------

# 四、教程缺少双网卡问题说明

真实机器人电脑经常存在：

有线：

    192.168.1.5

无线：

    192.168.2.227

Linux可能默认：

    default route -> WiFi

导致：

-   SDK发现异常
-   UDP数据走错接口
-   ROS没有点云

建议：

调试 MID360：

关闭 WiFi。

或者：

调整路由优先级。

------------------------------------------------------------------------

# 五、正确配置流程

## 1. 查看电脑网卡

    ip addr

确定：

    eth/enp网卡

------------------------------------------------------------------------

## 2. 找到雷达真实IP

不要猜。

使用：

    livox_lidar_info_get

------------------------------------------------------------------------

## 3. 修改雷达IP

使用：

    livox_lidar_ip_set

例如：

    ./livox_lidar_ip_set config.json \
    192.168.1.10 \
    255.255.255.0 \
    192.168.1.1

成功：

    SetLivoxLidarIp OK

------------------------------------------------------------------------

## 4. 修改 ROS 配置

最终：

电脑：

    192.168.1.5

雷达：

    192.168.1.10

配置一致。

------------------------------------------------------------------------

# 六、其它教程常见不严谨点

## 1. 没说明网关是否必须

局域网直连：

网关实际上不是必须。

例如：

    电脑 192.168.1.5
    雷达 192.168.1.10

可以通信。

设置：

    192.168.1.1

只是常见家庭网络写法。

------------------------------------------------------------------------

## 2. 没说明 ping 不一定可靠

很多人看到：

    ping 不通

认为雷达坏了。

实际上：

部分设备可能不响应 ICMP。

应该结合：

    livox_lidar_info_get
    tcpdump
    SDK日志

判断。

------------------------------------------------------------------------

## 3. 没说明配置修改后是否需要重新编译

JSON通常运行时读取。

修改：

    MID360_config.json

一般不用重新编译 SDK。

------------------------------------------------------------------------

## 4. 没区分 ROS1 / ROS2

很多教程混用：

ROS1：

    roslaunch

ROS2：

    ros2 launch

配置方式类似，但启动命令不同。

------------------------------------------------------------------------

# 七、本次故障复盘

## 初始状态

电脑：

    192.168.1.5

配置：

    lidar_configs:
    192.168.1.192

实际雷达：

    192.168.2.192

结果：

可以发现设备广播：

    Handle detection data

但是控制通信失败：

    Query livox lidar Fw type failed -4

------------------------------------------------------------------------

## 修复

执行：

    livox_lidar_ip_set

    192.168.2.192
    →
    192.168.1.10

成功：

    SetLivoxLidarIp OK

然后修改 ROS：

    lidar_configs.ip

    192.168.1.10

恢复正常。

------------------------------------------------------------------------

# 八、最终经验

不要按照教程里的 IP 配置。

正确顺序：

    确认电脑IP
    ↓
    确认雷达真实IP
    ↓
    修改雷达IP
    ↓
    修改ROS配置
    ↓
    启动驱动
    ↓
    检查点云

核心原则：

> JSON配置描述网络关系，不负责改变硬件网络参数。

很多 Livox 教程的问题不是命令错误，而是隐藏了作者自己的网络环境。
